# HonestCar
 A web app to keep auto owners informed

This project was created during my cohort’s “Web App in a Week” competition, a fast-paced challenge to design, build, and deliver a working app under tight time constraints. I’ve thought about refactoring and cleaning up the code, but I’ve decided to leave it as it is. It serves as a testament to what I was able to build with only three months of experience in Spring Boot and Java. I was proud to be one of two winners of the competition.
